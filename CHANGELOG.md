
# Change Log

All notable changes to the "Log Cleaner" extension will be documented in this file.

## [0.0.1] - 2025-05-18

### Added
- Initial release
- Support for removing logs from current file or entire workspace
- Keyboard shortcuts: Ctrl+Alt+L and Ctrl+Alt+Shift+L
- Support for multiple programming languages:
  - JavaScript/TypeScript
  - Python
  - Java
- Configurable log patterns, file extensions, and exclusion folders
